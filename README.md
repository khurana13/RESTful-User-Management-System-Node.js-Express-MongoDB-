# User Management Web Application

> **Project Status:** Ongoing
>
> A user management web application built using Node.js, Express.js, MongoDB, Mongoose and EJS.

The application currently supports creating, viewing, updating and deleting user records through a server-rendered interface.

## Features

- Create user records
- View all users
- Update user details
- Delete user records
- Store data using MongoDB
- Render pages using EJS

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- HTML and CSS

## Project Status

This project is currently under development. Input validation, improved error handling and additional features will be added in future updates.
